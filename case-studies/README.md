# IT Support Case Studies

This page collects six entry-level IT support case studies drawn from my hands-on portfolio projects. Each one walks through a single support workflow — what the problem was, how I worked through it, what proof exists in the repo, and what it shows for a help desk or IT support role.

These are **labs, simulated support workflows, and personal portfolio projects** — not professional production work. There are no real employers, clients, end users, or live company systems involved. Test accounts, lab domains, and trial tenants are used throughout, and anything simulated is labeled as simulated. The goal is to show practical support habits honestly: gather evidence, follow safe steps, document clearly, and know when to escalate.

## Case Studies

1. [Microsoft 365 / Entra ID User Support Lab](01-microsoft-365-entra-id-user-support.md)
   Cloud user lifecycle support — onboarding, licensing, password reset, sign-in block/restore, and offboarding using the admin centers and read-only-style Microsoft Graph PowerShell checks.

2. [Active Directory User Support Lab](02-active-directory-user-support-lab.md)
   Core Active Directory account support on Azure VMs — domain join, OUs, users, groups, RDP, DNS, password resets, account unlocks, and disable/enable.

3. [Help Desk Homelab — Windows Domain Support](03-help-desk-homelab-windows-domain-support.md)
   Local Windows domain built in VirtualBox — Active Directory, shared folders, mapped drives, Group Policy basics, and documented ticket writeups.

4. [osTicket Help Desk — Ticket Lifecycle](04-osticket-ticket-lifecycle.md)
   Full ticket lifecycle in a real ticketing system — intake, categorization, internal notes, user replies, and resolution tracking across six common scenarios.

5. [Windows Command-Line Troubleshooting Lab](05-windows-command-line-troubleshooting.md)
   Gathering diagnostic evidence before escalation — ipconfig, ping, tracert, nslookup, systeminfo, tasklist, and netstat with privacy-cleaned output.

6. [PowerShell Read-Only Help Desk Checks](06-powershell-read-only-help-desk-checks.md)
   A read-only PowerShell toolkit for first-level Windows checks — system info, disk space, network connectivity, local users, and recent event log errors.

*All projects are documented on GitHub with screenshots, ticket writeups, scripts, and reports. Each case study links back to the type of proof available in its source repo.*
